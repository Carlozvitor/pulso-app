# Empresa

> Memória central do projeto. O Claude lê esse arquivo antes de cada resposta.

**Nome:** PULSO
**Negócio:** Projeto pessoal (não é SaaS, não tem clientes)
**O que faz:** App mobile-first (PWA) de produtividade pessoal que responde "O que merece minha atenção agora?" — transforma caos em uma próxima ação clara.
**Perfil:** Solo — Carlos é o desenvolvedor e o único usuário
**Atende clientes:** Não
**Equipe:** Só o Carlos (com Claude como dev principal)
**Ferramentas:** Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui, Supabase (Postgres + Auth), Zod, React Hook Form, Lucide
**Principais entregas:** O app PULSO, construído em fases (ver `estrategia.md`)

## Contexto adicional

- Fluxo do produto: CAPTURAR → ENTENDER → PRIORIZAR → AGIR.
- Telas principais: Agora | Inbox | + (captura) | Agenda | Mais.
- O PULSO NÃO é: clone de Notion/Trello/Todoist/Calendar, app de hábitos, gamificação, dashboard, chatbot, app cheio de configurações ou dependente de IA.
- Regra fundamental: antes de qualquer funcionalidade, perguntar "Isso ajuda o usuário a saber o que merece sua atenção agora?"
- Documento mestre completo: `_memoria/contexto-mestre.md`.
